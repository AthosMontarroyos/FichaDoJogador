# INSTRUÇÕES PARA O ASSISTENTE AI

## Regras Obrigatórias

1. **Sempre crie um arquivo `ocdata`** dentro da pasta `opencode data/` no início de cada conversa contendo a data e o resumo da conversa.

2. **Leia todos os arquivos de `opencode data/`** antes de iniciar qualquer resposta, para entender o contexto das conversas anteriores.

3. **Atualize o `ocdata`** conforme a conversa for avançando, registrando decisões importantes e o progresso.

4. **Sempre leia os ArquivosDeInstrucao/** localizados em:
   - `/home/kurutta/Projetos/SiteFicha/ArquivosDeInstrucao/`
   - `/home/kurutta/Projetos/SiteFicha/ArquivosDeInstrucao/rascunho/`
   
   Estes diretórios contêm arquivos `.txt` com informações sobre a ficha do personagem (SMP Cósmico) que está sendo criada no site.

## Arquivos de Instrução Disponíveis

- `ArquivosDeInstrucao/CriacaoEntidade.txt` - Perguntas padrão e sobre o personagem para criação de entidade
- `ArquivosDeInstrucao/Deuses.txt` - Lista dos deuses do cosmos (Chronos, Hikaru, Bea-zebuB, Lami, Yume, Azaze, Mello, Kyan, Soo-min, Lil, Iael)
- `ArquivosDeInstrucao/entidades.txt` - Requisitos e regras para criação de entidades
- `ArquivosDeInstrucao/guia.txt` - Guia do servidor Cósmi-co SMP
- `ArquivosDeInstrucao/historia.txt` - Lore do servidor (primeira e segunda temporada)
- `ArquivosDeInstrucao/rascunho/PerguntasPadroes.txt` - Respostas do usuário (ykurutta) para as perguntas padrão
- `ArquivosDeInstrucao/rascunho/PerguntasPersonagem.txt` - Rascunho do personagem Kurummi

## Fluxo de Trabalho

1. Ler `opencode data/` para contexto de conversas anteriores
2. Ler `ArquivosDeInstrucao/` e `ArquivosDeInstrucao/rascunho/` para informações da ficha
3. Responder baseado nas instruções e dados encontrados
4. Atualizar `ocdata` com o progresso da conversa
